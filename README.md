# 🚀 CodeCollab - Real-Time Collaborative Code Editor

## 📌 Overview

CodeCollab is a modern collaborative coding platform designed for real-time code sharing and teamwork.  
Users can collaborate, manage projects, and work together through an interactive coding environment.

> Backend and real-time collaboration features are currently under development.

---

# ✨ Features

- Modern responsive UI
- Authentication pages
- Dashboard interface
- Project management UI
- Clean user experience
- Scalable frontend architecture

# ⚙️ Installation

## Clone Repository

```bash

```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```
